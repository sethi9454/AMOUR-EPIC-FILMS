AMOUR EPIC FILMS — Website

Files:
- index.html: home page, portfolio cards, about and contact sections
- wedding.html: wedding portfolio gallery
- prewedding.html: pre-wedding portfolio gallery
- style.css: all styling and responsive layouts

How to use:
1. Extract the ZIP.
2. Open index.html in a browser.
3. Click Wedding or Before Forever to open each portfolio page.
4. Replace the sample image URLs in the HTML files with your own image filenames/URLs to use your photography.

This site uses only HTML and CSS. The sample portfolio photos and Google Fonts need an internet connection.
